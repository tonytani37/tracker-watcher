# External Data Watcher

閲覧中のWebサイトから、外部のCX（顧客体験）プラットフォーム・アクセス解析・マーケティングツール（KARTE、Google Tag Manager、HubSpot、Salesforceなど）へ送信される通信とペイロードをリアルタイムに検知・可視化するChrome拡張機能（Manifest V3対応）です。

## 開発の背景

現代のWebサイトでは、顧客体験向上やマーケティング分析のためにサードパーティ製の計測タグやSDKが広く組み込まれています。しかし、エンドユーザー側からは「裏側でどの外部サービスに、どのようなデータが送信されているか」が見えにくい構造になっています。

本ツールは通信を強制ブロックするのではなく、**「今どの外部サービスへデータが送られているか」「個人情報入力フォームがあるページで外部CXツールが動いていないか」を透明化し、ユーザーやサイト管理者がリスクを判断できるようにすること**を目的としています。

## 主な機能

1. **外部ツール通信のリアルタイム検知＆バッジ表示**
   - 閲覧中サイト（ファーストパーティ）以外の外部ドメインへのHTTP/HTTPS通信を `chrome.webRequest` で監視します。
   - 主要なCX・MA・解析ツール（KARTE、HubSpot、Salesforce、Google Analytics、Meta Pixel、LINE Tag、Microsoft Clarityなど）を自動判別し、アイコン上のバッジに件数を表示します（高リスク分類のツール検知時は赤色バッジで通知）。
2. **個人情報入力フォーム連動の警告バナー**
   - ページ内にメールアドレス、パスワード、氏名、住所、電話番号、クレジットカードなどの入力フォームが存在し、かつ外部CXツールが動作している場合、画面最上部に警告バナーを表示します（SPAの動的描画にも対応）。
3. **POSTリクエストのペイロード（送信データ本体）検査**
   - `POST` や `sendBeacon` 等で外部サーバーへ送信されるデータ本体（JSON / formData）をローカルで解析し、生メールアドレス、SHA-256ハッシュ値、会員・個人属性キー（`email`、`user_id`、`member_id` 等）の送信有無とペイロードの先頭プレビューをポップアップに表示します。
4. **未知の外部POST / API通信の記録**
   - 定義済み辞書に含まれないサードパーティドメインへの `POST` / `ping` / `XHR` 通信もリストアップして可視化します。

## ディレクトリ構成

ビルドツールや外部ライブラリは一切使用しておらず、素のJavaScript / HTML / JSONのみで構成されています。

```text
.
├── manifest.json   # Chrome拡張機能のマニフェスト（Manifest V3）
├── background.js   # 通信監視・ペイロード解析・状態管理（Service Worker）
├── content.js      # 入力フォーム検知・警告バナー描画（Shadow DOM）
├── popup.html      # ツールバーアイコンクリック時のUI
├── popup.js        # 検知レポートの描画ロジック
└── README.md
```

## インストール方法（ローカル環境での読み込み）

1. このリポジトリをクローンまたはZIPダウンロードして展開します。
   ```bash
   git clone https://github.com/tonytani37/external-data-watcher.git
   ```
2. Google Chrome を開き、アドレスバーに `chrome://extensions/` と入力して拡張機能管理画面を開きます。
3. 画面右上の **「デベロッパーモード」** をオンにします。
4. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、展開したフォルダを選択します。
5. ツールバーにアイコンが追加され、Webサイトを閲覧すると自動的に監視が開始されます。

## プライバシーとセキュリティについて

- **完全ローカル動作:** 本拡張機能が検知した通信ログやペイロードの解析結果は、すべてお使いのブラウザのメモリ内でのみ処理されます。外部サーバーへのデータ送信やテレメトリ収集は一切行いません。
- **タブ単位の自動破棄:** ページ遷移時およびタブを閉じたタイミングで、該当タブの検知データはメモリから即座にクリアされます。

## 免責事項

- 本ツールはWebサイトの裏側で行われている通信の可視化・監査を支援するものであり、特定のサービスや企業の脆弱性・不正利用を断定するものではありません。
- 一部のSDKが独自形式やgzip等でペイロードを圧縮・難読化して送信している場合、プレビュー欄にバイナリ文字列が表示されることがあります。
